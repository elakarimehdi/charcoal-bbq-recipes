# Charcoal barbecue menus

Eight pork-free menus for TM7 preparation and Bull Bison charcoal cooking.

Open https://elakarimehdi.github.io/charcoal-bbq-recipes/

Each HTML page contains one schema.org Recipe JSON-LD object and matching visible ingredients and instructions. The pages need no build step. Configure GitHub Pages to deploy main / root.

We have not kitchen-tested these recipes. Cookidoo rejected the Japanese GitHub Pages URL in the signed-in Created Recipes importer on 15 October 2026. It reported: “Importing from this website is currently not approved. Only import from Cookidoo or Vorwerk community sites is allowed.” Manual entry remains the available route for these pages. JSON-LD does not set native TM7 controls.

The prior Japanese HTML attachment was unavailable. We reconstructed its ingredients and method from the recovered conversation and corrected the TM7 lid-cap instruction. We preserved all eight agreed menu combinations.
